# Local AI video summary prototype

Owner test only. No cloud AI account, API key, paid API, production deployment or public release. The Android feature is hidden unless both BuildConfig.DEBUG and the explicit `-PaiSummaryBaseUrl=http://127.0.0.1:8766` setting are present.

The app sends only a public LBRY claim URI to a loopback Mac server through `adb reverse tcp:8766 tcp:8766`. The Mac resolves the claim through the public LBRY service, confirms a free video, downloads a direct HTTPS file from player.odycdn.com, transcribes speech with faster-whisper base, and summarizes it using Qwen2.5-0.5B-Instruct locally. Download redirects are restricted to the same public host. No account credentials or wallet data are accessed or sent.

Limits: first 300 seconds of audio, 150 MB whole video download, direct files only (no HLS playlists), one active job, eight in-memory jobs retained for up to 30 minutes. Five-minute coverage is prominently labeled. These small models can hallucinate or mishear speech; they cannot describe visual-only content. There is no automatic download fallback or retry against a rate-limited video host. The current two public sample downloads returned HTTP 429, so end-to-end public video summarization is not yet verified. Error messages explain the host limit. Local synthetic speech-to-summary succeeded.

Setup: create a Python 3.9 virtual environment outside the repository, install requirements.txt, and run `LocalEngine(cache_path).load(offline=False)` once to download the models (about 1.2 GB). Downloads come from the upstream model repositories. Subsequent server starts load models offline with `python server.py --cache /absolute/model/cache`. Dependencies and model weights are not bundled in the APK or Git. Model repositories: https://huggingface.co/Systran/faster-whisper-base and https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct. Inference uses no cloud model service.

The server listens only on 127.0.0.1:8766. It is not designed for public exposure. Requests require the app marker header, reject browser Origin headers and unrecognized Host headers, and have bounded request bodies. The marker is not a secret/authentication mechanism. Downloaded media is removed with the job's temporary directory on normal completion/failure. Closing a screen cancels client polling but lets already-started local processing finish. A repeated request for the same video reuses its job/result within 30 minutes. Restarting the server clears all in-memory results. No transcripts or summaries are written to a database.

Validation: three Python policy/job tests; 24 Android JVM tests; ARM64 debug build and Android lint with existing baseline; synthetic speech was successfully transcribed and summarized locally. Phone installation succeeded, server health passed, and the USB reverse connection was created. Manual phone summary result pending. Public-host download rate limiting remains an open integration issue.

Run Python checks with `python -m unittest discover -s summary-server -v` from the repository root. Android build: `bash ./gradlew -PaiSummaryBaseUrl=http://127.0.0.1:8766 assemble__64bitDebug`. To stop testing, stop the server and remove only this mapping with `adb reverse --remove tcp:8766`. Do not uninstall/clear wallet-bearing apps.
